# Проверки сборщика

Дата: 2026-10-01. Среда: Windows, Python 3.12, PlatformIO Core 6.2.0,
MSVC для native harness. Проверки 2026-09-30 были offline; аппаратная приёмка
T-Beam из сборщика началась 2026-10-01 и описана отдельно ниже.

## Текущая версия: builder 0.1.0a2, server 0.1.0a8

### Терминальный мастер — 2026-10-01

Команда `wizard` объединяет выбор платы/опций, подготовку исходников, полную
сборку, сборку готового workspace, анализ обновления и операции восстановления.
**30 новых тестов** проверяют независимые опции и выключенные значения по
умолчанию, отмену/EOF/Ctrl+C, повтор некорректного ввода, пути с пробелами и
символами оболочки, запрет вложенных рабочих каталогов, порядок CLI-этапов и
остановку после ошибки каждого из них. Проверены реальные offline-операции с
синтетическими flash-копиями, несовместимый manifest и незавершённый пакет.

Полный прогон: **183 теста прошли без пропусков** за 78,05 с, включая существующие
upstream/native проверки. В настоящем Windows-терминале мастер проанализировал
сохранённую копию T-Beam и подтвердил запас 13 408 байт; отмена сохранения отчёта
завершила сценарий без новых файлов. Сеть, плата и сервер не использовались.
Полная компиляция через меню отдельно не повторялась: проверены оркестрация
мастера и существующие CLI-команды. Инструкция запуска находится в README.

### Пакет восстановления — 2026-10-01

Добавлены `prepare-recovery` и `verify-recovery`. **25 новых тестов** проверяют
побайтную сохранность полной копии и извлечённого приложения, factory/второй OTA
слот, блокирующие состояния, запрет перезаписи, повреждение каждого файла,
подмену адреса с пересчитанными хешами, незавершённый пакет и ошибку записи.
Проверены перенос пакета без исходного файла, детерминированность, однократное
чтение источника, CLI и отсутствие сети/подпроцессов.

Полный прогон: **153 теста прошли без пропусков**, включая upstream-матрицу,
сравнение с подготовленной legacy-прошивкой и native harness. Время — 78,40 с.
На приватной копии T-Beam создан пакет из пяти файлов: full flash 8 388 608 байт,
прежнее приложение 2 411 072 байта, manifest, SHA256SUMS и инструкция. Хеш
извлечённого приложения совпал с известным образом 1/3. Проверка файлов прошла;
плата и сервер в этом этапе не использовались. Пакет содержит приватные данные
и остаётся в защищённой локальной папке, вне репозитория и дистрибутива.

Это не является проверкой загрузки всех зависимостей с нуля.

не менял контрольные суммы ресурсов.

не подтверждена; перед записью требуется её отдельная проверка.

- Linux-компиляция и бинарные сборки всех промежуточных сочетаний экранных опций;
- побайтовое воспроизведение образов на разных машинах;
- платы кроме пяти зарегистрированных профилей, другие версии Meshtastic;
- прошивка, сохранность конфигурации и USB на Heltec V3 и трёх новых платах; радио на пяти платах;
- iPhone/dedupe, multi-hop, штатная кнопка Client History и серверные каналы.

Пройденные native тесты проверяют USB bridge со stub sender, а не физическую
радиодоставку. Существующие проверки прежней персональной прошивки не переносятся
автоматически на новые сборки.
