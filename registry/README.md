# Реестр совместимости

Начальная реализация хранит записи в `catalog.json`:

- `upstreams`: точные firmware/protobuf commit, версия PlatformIO,
  упорядоченные патчи и их SHA-256;
- `boards`: PlatformIO environment, hardware model, архитектура, транспорт,
  параметры памяти и форматы артефактов;
- `profiles` и `options`: базовый профиль и независимые дополнительные опции.
- `release_bases`: SHA-256 снимков входов сборки из закреплённого upstream,
  используемых при проверке возможности повторного применения lock к релизу.

Профиль `meshmemo` сохраняет обязательные патчи и payloads. `patches-only`
применяет только выбранные `options`: обязательные патчи, payloads, транспортные
флаги и заголовок UsbSfBuild отсутствуют. Windows workaround при `auto` выключен;
его можно включить явно. Существующие идентификаторы профиля MeshMemo не меняются.

`release-bases/2.7.26.json` содержит commit и Git-объекты входов сборки.
Правило отбора реализовано в `releases.build_input`; изменение правила требует
пересоздания снимка и его SHA-256. Это проверка совместимости зависимостей,
а не отметка об аппаратной поддержке нового релиза.

Зарегистрированы пять профилей ESP32-S3 на базе 2.7.26: T-Beam S3 Core,
Heltec V3, Wireless Stick Lite V3, Wireless Tracker V1.1 и T-LoRa T3-S3.
При разрешении профиля проверяются версия схемы, идентификаторы, commit,
доступность опций и SHA-256 ресурсов. У каждого профиля свой lock транзитивных
зависимостей Windows AMD64. Полная JSON Schema пока не реализована.

`supported_options` ограничивает дополнительные опции конкретного профиля;
для прежних профилей отсутствие поля сохраняет доступность всех общих опций.
Stick Lite V3 поддерживает только UA22. `windows_patches` добавляются после общего
Windows workaround только для выбранной платы. Это позволяет расширять список
плат без изменения build ID уже существующих профилей.
`windows_lto: enabled` у T-LoRa означает сохранение upstream LTO: отключение
оптимизации переполняет штатный раздел. Этот профиль не применяет дополнительный
патч отключения LTO; общие патчи T-Beam/Heltec не меняются.

Статусы нужно хранить отдельно: сборка, USB, радио, проверенные версии клиентов.
Разметка из профиля платы не заменяет чтение фактической разметки перед обновлением.
