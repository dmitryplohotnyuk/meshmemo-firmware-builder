# Реестр совместимости

Начальная реализация хранит записи в `catalog.json`:

- `upstreams`: точные firmware/protobuf commit, версия PlatformIO,
  упорядоченные патчи и их SHA-256;
- `boards`: PlatformIO environment, hardware model, архитектура, транспорт,
  параметры памяти и форматы артефактов;
- `profiles` и `options`: базовый профиль и независимые дополнительные опции.

Есть одна разрешённая пара: T-Beam S3 Core / 2.7.26. При разрешении профиля
проверяются версия схемы, идентификаторы, commit и SHA-256 ресурсов.
Полная JSON Schema и lock транзитивных зависимостей остаются следующими задачами.

Статусы нужно хранить отдельно: сборка, USB, радио, проверенные версии клиентов.
Разметка из профиля платы не заменяет чтение фактической разметки перед обновлением.
